## Billing Rules

- Count output thinking tokens on the output side.
- Do not infer actual cache savings from the presence of a continuation ID; use provider usage metadata.
- Search pricing is query-based, and one submitted prompt can produce multiple billable search queries.
- Image per-image values are official equivalents; token usage remains the authoritative provider meter when returned.
