# OpenAI Pricing Matrix

Use this file as the structured billing source for documented OpenAI rows.

## Scope

- Currency: `USD`.
- Processing tier: direct OpenAI `Standard` only.
- Short context means a request with at most `272K` input tokens.
- Long context means a request with more than `272K` input tokens; the published long-context rates apply to the full request.
- Eligible regional-processing endpoints add a published `10%` uplift. That conditional uplift is not baked into the `global` rows below.
- Batch, Flex, Priority, hosted-tool call fees, storage fees, and third-party platform billing are outside this local matrix. Add separately verified rows before estimating those paths.
- Cache writes for GPT-5.6 are separately metered; never treat `cache-write` as ordinary uncached input.
