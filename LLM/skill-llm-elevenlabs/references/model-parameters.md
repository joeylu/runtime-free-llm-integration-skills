## Precedence

- Exact model-and-surface documentation overrides generic ElevenLabs voice/settings documentation.
- A field marked `deprecated` is not emitted by new integration code.
- A field marked `unknown` stops the request if the caller explicitly asks for it.
- The Scribe v2 3 GB local ceiling is intentionally stricter than one conflicting endpoint-reference statement; the conflict must remain visible until ElevenLabs resolves it.
